Project Type:
Artificial Intelligence / Machine Learning Capstone Project

-----------------------------------------------------------
PROJECT OVERVIEW
-----------------------------------------------------------

This project develops an AI-based crop health monitoring system using
multispectral vegetation indices obtained from drone imagery. The goal is
to identify healthy and stressed crop regions using machine learning
algorithms and generate field-level crop stress heatmaps for precision
agriculture.

The dataset contains processed multispectral vegetation indices rather
than raw drone images. Each row represents a spatial observation collected
from an agricultural field.

-----------------------------------------------------------
OBJECTIVES
-----------------------------------------------------------

• Understand vegetation indices used in crop health monitoring.
• Train machine learning models to classify crop stress.
• Evaluate model performance using multiple evaluation metrics.
• Generate field-level crop stress heatmaps.
• Recommend drone inspection strategies based on stress severity.
• Compare different machine learning models.

-----------------------------------------------------------
DATASET FEATURES
-----------------------------------------------------------

The dataset includes the following vegetation indices:

• NDVI (Normalized Difference Vegetation Index)
• GNDVI (Green NDVI)
• SAVI (Soil Adjusted Vegetation Index)
• EVI (Enhanced Vegetation Index)
• Red Edge Index
• Canopy Density
• Moisture Index

Target Variable:
Crop Stress Classification
(Healthy / Stressed)

-----------------------------------------------------------
MACHINE LEARNING MODELS
-----------------------------------------------------------

The following classification algorithms were implemented:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Stochastic Gradient Descent (SGD)

RESULT SUMMARY
-----------------------------------------------------------

Among the evaluated machine learning models:

• Logistic Regression provided a strong baseline model.
• Decision Tree offered easy interpretation.
• Random Forest improved prediction performance using ensemble learning.
• Stochastic Gradient Descent (SGD) achieved the best overall
  classification performance for this dataset.

DRONE & AGRONOMY INTERPRETATION
